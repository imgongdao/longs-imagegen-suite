# Longs ImageGen Suite

Longs ImageGen Suite（多略生图套件）是一组面向 Codex 的图片生成 Skills，覆盖微信公众号头图、小红书封面、视觉解释图和儿童教育小册子。

由 [GongDao](https://imgongdao.com) 创建，归属 **Longs（多略）**。访问 [Longs.xyz](https://Longs.xyz) 了解更多。

## Included Skills

- [`longs-imagegen-wechat-header`](./longs-imagegen-wechat-header/) — 微信公众号头图
- [`longs-imagegen-xiaohongshu-cover`](./longs-imagegen-xiaohongshu-cover/) — 小红书封面图
- [`longs-imagegen-visual-explainer`](./longs-imagegen-visual-explainer/) — 概念、关系、流程与解释型视觉化图片
- [`longs-imagegen-kids-educational-booklet`](./longs-imagegen-kids-educational-booklet/) — 儿童教育小册子与连续多页教学资产

仓库根目录的 [`Longs-ImageGen-HARNESS.md`](./Longs-ImageGen-HARNESS.md) 是整套视觉生产规范。每个 Skill 也包含可独立安装和使用的必要文件。
