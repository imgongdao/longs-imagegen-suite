# 多略视觉化图片 Style Modes

This file defines the main visual-surface and presentation families available to the longs-imagegen-visual-explainer skill.
These modes are not the same as structure types.
Structure answers: what is the logic?
Style mode answers: what visual container or surface will make that logic easiest to understand, remember, and share?

Use this file to choose the best presentation mode intentionally.
Do not choose a style because it is fashionable if it weakens comprehension.

## 1. WHITEBOARD
Best for:
- general teaching
- workflow explanation
- frameworks
- grouped insights
- article summaries
- process and decision logic

Visual characteristics:
- clean whiteboard background
- marker-like diagrams
- boxes, arrows, labels, grouped regions
- simple color highlights
- readable teaching layout

Strengths:
- highly versatile
- instantly readable
- feels like live explanation
- one of the safest and most broadly liked educational formats

Risks:
- can become generic
- can become box-heavy and boring if the structure is weak

Use when no stronger surface logic exists.
This is the safest default.

## 2. NAPKIN
Best for:
- founder ideas
- entrepreneurial concepts
- rough business models
- first-principles explanation
- “here is the simple truth” style visuals

Visual characteristics:
- paper napkin or café-note surface
- hand-drawn arrows / labels / blocks
- rough sketch energy with controlled clarity

Strengths:
- memorable
- conveys quick insight
- good for stripping complex ideas to essentials
- highly shareable when the insight itself is sharp

Risks:
- can look too casual
- not ideal for heavily technical or highly formal content

Use when the message benefits from “simple, stripped-down, smart sketch” energy.

## 3. CHALKBOARD
Best for:
- principles
- frameworks
- teaching concepts
- classroom-style explanation
- equations or layered conceptual maps

Visual characteristics:
- dark board background
- chalk-style text and lines
- educational, professor-like tone

Strengths:
- strong teaching cue
- supports conceptual explanation well
- good for organized principle lists and model diagrams

Risks:
- can reduce readability if text is too small
- can feel old-school if overused

Use when educational framing helps trust and memory.

## 4. A4 PAPER / ONE-PAGER
Best for:
- article companion visuals
- report summaries
- printable explainers
- cleaner, more editorial summary pages
- polished single-page notes

Visual characteristics:
- clean paper sheet or flat page
- ordered blocks, labels, light annotations
- looks like a smart annotated summary page

Strengths:
- clean and versatile
- good text readability
- good for concise summaries
- one of the most practical and reusable modes

Risks:
- can become too static or document-like

Use when the visual should feel like an intelligent one-page summary.

## 5. STICKY NOTES WALL / KANBAN BOARD
Best for:
- grouped ideas
- categorization
- brainstorm-to-structure visuals
- prioritization
- content buckets
- project views, task grouping, opportunity mapping

Visual characteristics:
- sticky notes or card clusters on a board/wall
- categories separated by columns or areas
- handwritten or card-label feel

Strengths:
- very popular and familiar
- strong sense of organization emerging from chaos
- good for “many fragments turned into structure” stories
- high social shareability because it feels actionable

Risks:
- can become cluttered very fast
- too many notes destroy hierarchy
- often weaker for deep causal explanation

Use when the source input starts messy and the visual’s job is to group, prioritize, or organize.

## 6. NOTEBOOK / STUDY PAGE
Best for:
- learning notes
- study summaries
- memory aids
- educational lists or mnemonic visuals
- simplified notes for children or beginners

Visual characteristics:
- notebook-style page
- annotations, bullets, highlights, mini diagrams
- student-friendly organization

Strengths:
- approachable
- strong memory cue
- easy to read
- effective when the visual should feel like “smart study notes”

Risks:
- can look too juvenile if handled poorly
- can become too scribbly

Use when the image should feel like a clean, memorable learning note.

## 7. CLEAN INFOCARD / LIGHT POSTER
Best for:
- public shareability
- social content support images
- compact summaries
- simple comparisons or takeaways
- concise professional education visuals

Visual characteristics:
- clean background
- card-based or block-based organization
- light poster feel
- higher polish than rough teaching surfaces

Strengths:
- very shareable
- readable
- works well for compact takeaways
- often performs well as a “save-worthy” knowledge card

Risks:
- can drift too close to a cover/poster if the explanatory structure is weak
- can become overly generic if too templated

Use when the result should be polished, social-friendly, and concise.

## 8. MAGAZINE / EDITORIAL SPREAD
Best for:
- article summaries
- premium-feeling explainers
- long-form commentary visuals
- report digest pages
- “smart media” style visual notes

Visual characteristics:
- editorial page layout
- headline + section blocks + pull quotes / callouts
- feels like a well-designed magazine page or newspaper analysis panel

Strengths:
- high perceived quality
- highly suitable for turning articles into visual summaries
- attractive to professional audiences

Risks:
- easy to over-text
- can become layout-first and explanation-second

Use when the visual should feel polished, media-like, and intelligent.

## 9. DESKTOP / TABLETOP OBJECT EXPLAINER
Best for:
- toolkits
- workflows using real objects
- memory-oriented metaphors
- process explanation where physical props help
- creator/operator desk scenes

Visual characteristics:
- desk/table background
- paper notes, sticky notes, devices, tools, cards, objects
- objects act as anchors or categories

Strengths:
- tactile and memorable
- helps abstract ideas feel concrete
- often visually rich without needing much abstraction

Risks:
- can become too decorative
- objects can distract from the actual logic

Use only when the physical scene improves understanding.

## 10. FUTURISTIC FLOATING UI
Best for:
- AI systems
- product relationships
- architecture diagrams
- benchmarking summaries
- platform maps
- agent / workflow / infrastructure explanation

Visual characteristics:
- floating windows/cards/panels
- soft 3D interface feeling
- structured UI-like modules in space
- futuristic but organized

Strengths:
- strong fit for AI topics
- good for systems and stack explanations
- visually impressive while still teachable
- highly popular in AI visual content when kept readable

Risks:
- easy to over-style
- can become flashy and less readable if overloaded

Use when the topic is strongly tied to AI/product/system logic.

## 11. DASHBOARD / CONTROL PANEL
Best for:
- metric summaries
- benchmark comparison
- operating system views
- business performance explanation
- “what the indicators say” style analysis

Visual characteristics:
- dashboard panels
- gauges, cards, ranking blocks, metric areas
- control-room or analytics-console feeling

Strengths:
- very effective for “decision support” visuals
- naturally supports comparison and monitoring themes
- highly familiar from SaaS and BI tools

Risks:
- fake dashboards are useless if they contain meaningless micro-data
- can feel cold or corporate if overdone

Use when key signals, indicators, or comparisons are central to the explanation.

## 12. BLUEPRINT / GRID / SCHEMATIC
Best for:
- systems thinking
- architecture
- layered frameworks
- structured planning
- “how this is built” explanations

Visual characteristics:
- blueprint-like grid or engineering surface
- diagram lines, labels, modular blocks
- more schematic than illustrative

Strengths:
- strong sense of precision
- good for technical and architecture-heavy topics
- memorable for product/system explanations

Risks:
- can become too engineer-centric
- may intimidate general audiences if overcomplicated

Use when the topic benefits from a “constructed system” feel.

## 13. MOBILE SCREEN / CAROUSEL MOCKUP
Best for:
- social-media-native explainers
- step-by-step visual posts
- app/workflow explanation
- content that will be repurposed for mobile platforms

Visual characteristics:
- phone-screen framing or stacked mobile cards
- swipe/post-like layout feeling
- clean blocks optimized for small-screen scanning

Strengths:
- highly familiar and high-performing on mobile social platforms
- great for concise step-based explainers
- strong “save/share” energy

Risks:
- can look too platform-specific
- can feel gimmicky if a phone frame adds no value

Use when the output is explicitly intended for social sharing or mobile-native learning.

## 14. TIMELINE / ROADMAP BOARD
Best for:
- history of events
- rollout plans
- development stages
- product evolution
- before-now-next explanation

Visual characteristics:
- horizontal or vertical timeline
- milestones, checkpoints, phases, dates, arrows
- roadmap structure

Strengths:
- immediately understandable structure
- excellent for chronological clarity
- works well for “what happened over time” content

Risks:
- becomes weak if the real logic is not chronological
- too many milestones make it unreadable

Use when time sequence is the main teaching structure.

## 15. MIND MAP / RADIAL IDEA MAP
Best for:
- conceptual overviews
- topic decomposition
- grouped brainstorming
- category exploration
- first-pass orientation to a topic

Visual characteristics:
- central node with radiating branches
- clustered ideas around a core concept
- branching hierarchy

Strengths:
- intuitive for overviews
- good for topic exploration and memory
- popular because it looks immediately like “organized thinking”

Risks:
- can become spaghetti if too many branches are included
- weaker for strict step-by-step logic

Use when the main job is decomposing one topic into meaningful branches.

## 16. QUADRANT / MATRIX BOARD
Best for:
- segmentation
- categorization
- priority frameworks
- strategy mapping
- comparing items across two dimensions

Visual characteristics:
- x-y grid or quadrant layout
- labeled axes
- positioned examples or categories

Strengths:
- excellent for strategic positioning
- very familiar in business content
- easy to remember when axes are meaningful

Risks:
- fake precision if placement is arbitrary
- weak if the content does not naturally fit two dimensions

Use when the source is truly about classification across two key dimensions.

## 17. ISOMETRIC 3D WORKSPACE
Best for:
- product ecosystems
- workflows across tools
- modular business or technical systems
- playful but professional explainer visuals

Visual characteristics:
- isometric perspective
- multiple modules/objects connected within one scene
- 3D workspace or miniature world feeling

Strengths:
- visually rich and memorable
- often receives strong engagement when the structure remains clear
- good for showing multiple connected components without flat clutter

Risks:
- easy to overcomplicate
- can become scene illustration instead of explanation

Use when multiple connected components need to feel like one navigable system.

## 18. SCRAPBOOK / COLLAGE BOARD
Best for:
- culture/trend summaries
- multi-source idea synthesis
- creative-topic explainers
- “signals from different places” type visuals

Visual characteristics:
- layered paper scraps, cutouts, notes, taped sections, mini visuals
- collage-like but still organized

Strengths:
- high visual appeal
- strong social shareability
- useful for trend or inspiration synthesis

Risks:
- can get messy fast
- weak for rigorous technical logic
- must be controlled tightly to avoid chaos

Use when the explanation benefits from combining multiple visual fragments into one theme.

## 19. COMIC STRIP / STEP PANEL EXPLAINER
Best for:
- beginner teaching
- simplified how-to content
- cause-and-effect stories
- “what happens next” explainers
- educational sequences that benefit from narrative

Visual characteristics:
- panel-based progression
- mini scenes or mini diagrams in sequence
- dialogue/caption style optional

Strengths:
- highly engaging
- strong for simple stories and procedural explanation
- easy to follow when the audience is broad

Risks:
- can become childish
- weak for dense expert material

Use when narrative sequence improves comprehension more than abstract diagramming.

## 20. GLASSMORPHIC CARD STACK / MODERN APP CARDS
Best for:
- modern tech explainers
- AI tool overviews
- grouped takeaways
- product capability stacks
- sleek but understandable system summaries

Visual characteristics:
- layered translucent cards
- soft depth and modern interface polish
- modular card stack organization

Strengths:
- very contemporary
- high perceived polish
- works well for grouped modules or layered takeaways
- popular in modern AI/tech design language

Risks:
- readability can collapse if transparency is overused
- can feel trendy but shallow if structure is weak

Use when a modern, polished, shareable tech aesthetic helps without harming clarity.

## 21. Selection heuristic
Choose in this order:
1. What structure type best matches the content?
2. What surface makes that structure easiest to understand?
3. What surface best matches the audience and publication context?
4. What surface is most memorable without harming readability?
5. What surface supports social shareability if that matters?

## 23. Anti-patterns
Never choose a style mode for novelty alone.
Avoid these mistakes:
- choosing a dark or textured surface that hurts text readability
- choosing a fancy mode that hides the structure
- forcing futuristic UI for a simple human concept
- forcing napkin/collage when the information needs precision
- overbuilding mobile frames, sticky notes, or dashboard widgets that do not actually explain anything
- using too many style cues at once

The mode is a teaching surface.
If it does not help the viewer understand faster, it is the wrong mode.
