# 多略视觉化图片 Recipes

Use these as reusable prompt blueprints.
They are not fixed templates.
Select the closest one, then adapt it to the content.

## Recipe 1: Article summary on A4 paper
Use case: article-to-visual summary
Primary request: create a visual explainer image that turns an article into an easy-to-understand one-page summary
Source type: article / long text
Audience: Chinese creators, entrepreneurs, and professionals
Teaching goal: help the viewer grasp the article quickly without reading the full original text first
Core question: what are the most important takeaways and how do they relate?
Structure type: SUMMARY
Title (verbatim): "[INSERT TITLE]"
Key blocks: [3–6 grouped takeaways]
Visual surface / style mode: A4 PAPER
Visual anchor: annotated one-page summary sheet
Layout: title + grouped section blocks + arrows or connectors only where useful
Diagram grammar: grouped cards, short callouts, minimal arrows
Style / medium: clean editorial teaching graphic
Color direction: restrained, readable, lightly color-coded
Typography: clean, medium-large labels, no paragraph walls
Constraints: summarize aggressively, keep text short, make scanning easy, no watermark
Avoid: walls of text, decorative clutter, tiny labels
