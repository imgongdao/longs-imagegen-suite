# 多略小红书封面 Brand Rules

## 1. Positioning
多略小红书封面 is not lifestyle-content packaging.
It is business-tech editorial packaging for a fast mobile feed.
The goal is to make complex AI/business topics instantly understandable and worth opening.

Core identity:
- sharp
- practical
- information-forward
- authoritative
- creator-friendly
- business-minded
- visually forceful without becoming vulgar

## 2. Source independence rule
A good 多略小红书封面 must be able to exist independently.
It must not rely on a 微信公众号头图 in order to become clear or strong.

If a 微信公众号头图 exists, it may act as an optional source anchor.
If it does not exist, nothing is missing.
The 小红书 cover must still be fully planned from:
- the topic
- the verdict or angle
- the main entities
- the user value proposition
- 多略’s visual grammar

If a 微信 cover is provided, preserve what is useful:
- central thesis
- primary entity selection
- overall tone family
- core color logic when useful

Adapt what must change:
- ratio
- title length
- headline pacing
- focal scale
- support detail density
- vertical composition

## 3. What 多略 consistently prefers
Based on historical selections, 多略 prefers the following:

### 3.1 Big readable headline
- the headline is usually the first visual object
- text often occupies major visual weight
- the title should not be shy
- the cover should still work when the viewer mainly notices the words first

### 3.2 One obvious thesis
- the cover should express a viewpoint, not merely a topic
- “why it matters” is preferred over “something happened”
- a decisive frame beats neutral ambiguity

### 3.3 Strong relationship expression
多略 covers often visualize relationships, such as:
- versus
- split
- win/lose
- decomposition
- source/result
- evidence/conclusion
- person/system
- local/cloud
- old/new

This is not optional decoration. It is part of the explanation.

### 3.4 Dominant hero anchor
- usually one big face, one big product symbol, one big central object, or one clear structural centerpiece
- too many equal-sized elements weaken performance

### 3.5 Brand-coded colors
- brand-associated colors are used as recognition accelerators
- examples: Claude orange, NVIDIA green, ByteDance blue, OpenAI cool tones
- color should help the story; it should not become noisy branding wallpaper

### 3.6 Organized information density
多略 does not prefer minimal emptiness.
It prefers structured richness.
This means:
- strong main title
- strong main image
- 1–3 secondary cues
- visual evidence or system cues when useful
- clear zones and hierarchy

### 3.7 Editorial drama, not cheap clickbait
Allowed:
- light streaks
- split scenes
- UI panels
- stage/podium
- diagnostic panels
- arrows/flows
- cinematic contrast

Not allowed:
- trashy exaggerated expressions
- emoji spam
- childish doodles
- random explosion effects
- pointless glowing clutter

## 4. What makes a cover feel “not 多略”
Avoid these failure modes:
- too cute
- too lifestyle-blog
- too soft and vague
- too academically dry
- too empty/minimal with no argument
- too many tiny unreadable labels
- too much faux-futuristic blue-tech wallpaper
- too many decorative logos with no story
- no clear value proposition

## 5. Xiaohongshu-specific differences from WeChat
Compared with 微信 cover, 小红书 cover should be:
- shorter in wording
- stronger in first-glance hook
- more vertical and compact
- more likely to use one dominant face/object
- slightly more scroll-stopping
- slightly less information-dense

But it should NOT become:
- low-brow clickbait
- overly cute
- entertainment gossip packaging

## 6. Headline rules
Preferred headline qualities:
- blunt
- useful
- provocative when true
- immediately understandable
- scannable on mobile

Preferred headline structures:
- X不是Y，而是Z
- 真正关键是X
- A赢在X / 输在X
- 别被X骗了
- X背后其实是Y
- X终于说明了Y
- X把Y彻底改变了
- 这三点最重要

Avoid headlines that are:
- too literary
- too abstract
- too diplomatic
- too long to scan instantly
- too dependent on reading a subtitle to make sense

## 7. Text density rules
Default preference:
- one dominant headline
- one small support line if needed
- one small label/tag if helpful

Avoid:
- more than four text groups
- long subtitle paragraphs
- too many capsules/badges
- too many explanatory micro-labels

## 8. Portrait rules
When a real person is central:
- face should be large
- expression should feel thoughtful, forceful, or strategically serious
- avoid awkward smiley stock-photo energy
- keep facial likeness clean and credible

When two people appear:
- tension or contrast should be visible
- they should not feel like two unrelated portraits pasted together

## 9. Logo and product rules
- logos support recognition but should not overwhelm the title
- 1–2 logos usually outperform many small logos
- when multiple brands appear, one must still be primary
- product/system cards or UI-like panels are often helpful when the product itself is the story

## 10. Composition preferences
Preferred:
- strong top title + lower image body
- title block on left, hero on right
- diagonal split comparison
- centered hero card with supporting flows
- large portrait with side context

Also acceptable when strategically stronger:
- headline stacked above a central hero object
- large portrait occupying upper half with text below
- top/bottom split for a two-sided comparison

Avoid:
- no focal point
- perfectly symmetric clutter
- all elements the same visual weight
- important elements near extreme edges

## 11. Allowed visual devices
Useful devices commonly aligned with 多略 style:
- VS marker
- split-screen contrast
- scorecard / dashboard block
- diagrammatic arrows / flows
- cloud/local metaphor
- platform cards
- diagnostic or evidence panel
- article-angle iconography used sparingly
- cinematic environmental context that supports the story

## 12. Color rules
- use contrast aggressively for readability
- keep title readable over background
- choose one dominant palette + one accent when possible
- let the main company/product help define the accent system
- do not create muddy multi-brand color chaos

## 13. Practical-value signal
Even a commentary post should suggest practical relevance.
The cover should imply one of the following:
- this changes the market
- this changes how you work
- this changes how you choose tools
- this reveals a trap/risk
- this creates an opportunity
- this explains a confusing shift clearly

If the cover feels like pure news with no user relevance, it is underperforming for 多略.

## 14. Quality bar
A good 多略小红书 cover should make the viewer think one of these:
- “This is worth clicking.”
- “This person has a strong read on the issue.”
- “I can understand this topic quickly from this post.”
- “This looks useful, not fluffy.”

If the cover only looks pretty, it failed.
