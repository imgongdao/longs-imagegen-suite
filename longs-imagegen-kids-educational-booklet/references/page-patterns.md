# Page Patterns

Select one primary pattern per page.

## P01 — Concept Definition

Use for: new term, method, rule, basic idea.

Structure:

`TITLE → ONE-LINE DEFINITION → VISUAL EXAMPLE(S) → TRY / RECALL`

## P02 — Wrong vs Better

Use for: correcting a misconception or ineffective behavior.

Structure:

`TITLE → WRONG METHOD → BETTER METHOD → EXAMPLE → ONE-LINE RULE`

MUST make the contrast visually unmistakable.

## P03 — Cause / Diagnosis

Use for: “为什么…？” / common failure modes.

Structure:

`QUESTION → 2–4 CAUSES → VISUAL DEMONSTRATION → KEY TAKEAWAY → MINI CHECK`

## P04 — Step-by-Step Procedure

Use for: routines, physical skills, workflows.

Structure:

`TITLE → STEP 1 → STEP 2 → STEP 3... → COMPLETION STATE`

MUST use consistent action framing and explicit sequence markers.

## P05 — System / Goal Clusters

Use for: several related systems or goals.

Structure:

`MASTER GOAL → 2–4 SUBSYSTEMS → EACH WITH 2–4 ACTIONS → SUMMARY`

## P06 — Capability Boundary

Use for: what I can do / need help / cannot do yet.

Structure:

`CATEGORY A | CATEGORY B | CATEGORY C`

MUST use clear visual coding and non-overlapping criteria.

## P07 — Problem-Solving Grid

Use for: repeatable thinking method.

Structure:

`1 → 2 → 3 → 4 → 5 → 6`

Each cell MUST contain one verb phrase + one concrete illustration.

## P08 — Example Ladder

Use for: phonics, reading, math patterns, concept transfer.

Structure:

`SIMPLE EXAMPLE → MEDIUM EXAMPLE → HARDER EXAMPLE → PRACTICE`

MUST preserve the same underlying rule across examples.

## P09 — Checklist / Routine

Use for: daily habits, preparation, review.

Structure:

`TITLE → CHECKLIST → ICON/SCENE SUPPORT → FINAL REMINDER`

## P10 — Compare / Choose

Use for: options, tradeoffs, “which is better”.

Structure:

`CHOICE A ↔ CHOICE B → DIFFERENCE → DECISION RULE → TRY`

## P11 — Demonstration Strip

Use for: body movements, tool use, operational actions.

Structure:

`FRAME 1 → FRAME 2 → FRAME 3 → FRAME 4`

MUST keep viewpoint and character scale stable across frames.

## P12 — Practice / Quiz

Use for: recognition, completion, matching, circling, recall.

Structure:

`PROMPT → 2–4 OPTIONS / BLANK → WRITING OR CHOICE AREA`

MUST leave real interaction space.

## Combination Rule

Allowed combinations:

- P01 + P08
- P02 + P08
- P03 + P12
- P04 + P12
- P05 + P06
- P07 + P12
- P09 + P12

NEVER combine patterns when the page gains a second competing thesis.
