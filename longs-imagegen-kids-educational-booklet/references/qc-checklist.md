# Kids Educational Booklet QC

A page is incomplete until all Critical checks pass.

## Critical — Content

- [ ] page thesis is singular and correct
- [ ] educational claim matches locked source content
- [ ] title is exact
- [ ] Chinese text is exact
- [ ] English text is exact
- [ ] phonics chunks / numbers / units / labels are exact
- [ ] step order is correct
- [ ] examples actually demonstrate the rule
- [ ] quiz/options have valid intended answers

## Critical — Visual Teaching

- [ ] child can identify the main subject/action quickly
- [ ] reading order is obvious
- [ ] illustration teaches the intended point
- [ ] action/tool/object relationship is physically clear
- [ ] arrows and motion cues are unambiguous
- [ ] comparison states are visually distinct
- [ ] practice area is usable

## Critical — Series Consistency

- [ ] recurring character identity matches bible
- [ ] art medium matches style lock
- [ ] palette family matches
- [ ] title hierarchy matches
- [ ] margins and module grammar match
- [ ] recurring icons/tokens match
- [ ] page numbering is correct

## Quality — Child Readability

- [ ] title is large
- [ ] body text is readable
- [ ] no excessive line length
- [ ] no dense paragraph wall
- [ ] 2–6 main modules maximum unless justified
- [ ] decoration does not compete with content
- [ ] enough whitespace around key blocks
- [ ] age level matches audience

## Quality — Image Integrity

- [ ] faces/hands are valid
- [ ] character limbs/actions are plausible
- [ ] key objects are recognizable
- [ ] no accidental crop of instructional content
- [ ] no random text
- [ ] no watermark
- [ ] no mixed incompatible rendering styles

## Patch Order

`content → text → character → reading order → overflow → consistency → object/action integrity → decoration`

MUST re-run affected Critical checks after every patch.

MUST run final series scan before delivery.
