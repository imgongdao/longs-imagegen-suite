# Typography & Layout

## Text Hierarchy

Use no more than 4 visual text levels per page:

1. `H1` page title;
2. `H2` module/step title;
3. `BODY` short explanation;
4. `LABEL` example / option / caption.

MUST make `H1` readable at thumbnail scale.

MUST keep BODY large enough for child reading.

NEVER solve overflow by globally shrinking text.

## Copy Density

Prefer:

- short title;
- 1–2 lines per explanation block;
- one thought per line;
- concise labels;
- visible line spacing;
- short paragraphs only when unavoidable.

If copy is too dense:

`cut → simplify → split page → reduce modules → only then reduce type size`

## Layout Grammar

Preferred:

- top title band / ribbon / clean heading zone;
- one core message directly below title;
- middle teaching modules;
- bottom summary / practice / action prompt;
- stable side margins;
- rounded or hand-drawn module borders;
- numbered circles for ordered sequences;
- arrows only for real direction/flow.

## Reading Order

MUST be visually unambiguous.

Use:

`top→bottom`, `left→right`, or numbered sequence.

NEVER rely on decoration to imply order.

## Text on Illustration

Avoid placing dense text directly over detailed artwork.

MUST provide calm background or dedicated text containers.

## Bilingual / Phonics

MUST preserve exact English spelling and chunk boundaries.

Examples MUST keep chunk segmentation as content, not typography decoration.

Do not substitute IPA, letter names, phonemes, syllables, or onset-rime unless source content explicitly uses them.

## Page Number

When used, keep placement consistent across all pages and visually secondary.
