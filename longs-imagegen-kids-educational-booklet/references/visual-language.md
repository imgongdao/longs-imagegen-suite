# Longs Kids Visual Language

## Default Identity

Target: warm, clear, child-friendly, educational, hand-made, visually ordered, print-friendly.

Default mode: `Chinese Watercolor Picture Book Style`.

## Canvas

SHOULD use portrait booklet composition by default.

For print-first tasks, SHOULD prefer A4-like portrait proportions unless user specifies otherwise.

MUST maintain stable page margins across the series.

## Background

Default:

- warm off-white / light cream paper;
- subtle paper grain or watercolor paper texture;
- low-contrast background;
- no heavy vignette;
- no dark full-page field unless explicitly requested.

## Hierarchy

Default:

`PAGE TITLE > CORE RULE / QUESTION > TEACHING MODULES > EXAMPLES / ACTIONS > SUMMARY / PRACTICE > DECORATION`

MUST keep one dominant title zone.

MUST separate content into obvious modules using whitespace, rounded boxes, soft borders, dashed borders, ribbons, tabs, numbered circles, or simple panels.

## Color Logic

Default anchor: deep navy / learning blue.

Accent family: green + warm yellow + orange + light blue; optional muted red/pink for emphasis.

MUST keep accents functional:

- blue: structure / title / neutral instruction;
- green: correct / healthy / can-do / positive;
- orange: attention / action / warning without fear;
- yellow: highlight / star / success / key note;
- red: sparse error/contrast emphasis only.

NEVER use all accents at maximum saturation simultaneously.

## Decorative Vocabulary

Allowed recurring tokens:

`sun | star | cloud | leaf | heart | pencil | book | speech bubble | light bulb | small arrows | check mark | simple stickers`

Decoration MUST remain subordinate to instructional content.

SHOULD reuse 2–4 recurring tokens across a booklet for series identity.

NEVER fill empty space only because it is empty.

## Information Density

SHOULD use 2–6 instructional modules per page.

MUST keep clear breathing room between modules.

MUST favor large meaningful illustrations over many tiny icons.

NEVER produce magazine-like dense poster layouts.
