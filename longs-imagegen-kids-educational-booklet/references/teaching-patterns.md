# Teaching Patterns

## Core Teaching Arc

Default:

`HOOK → EXPLAIN → SHOW → DO → SUMMARIZE`

Page-level use MAY contain only the relevant subset.

## Cognitive Rules

MUST teach one new central idea per page.

MUST convert abstraction into concrete action, object, example, sequence, choice, boundary, or cause.

MUST prefer observable verbs over moralizing labels.

MUST show desired behavior explicitly; do not rely only on warnings.

MUST separate `know` from `do` when both are required.

MUST place examples immediately after the rule they demonstrate.

SHOULD end instruction-heavy pages with one short recall, choice, completion, or action prompt.

SHOULD reuse familiar objects from children's daily life: schoolbag, cup, book, pencil, food, clothes, clock, toothbrush, toys, home/school scenes.

NEVER use fear, shame, ridicule, threat, or exaggerated danger as the main teaching mechanism.

## Age Calibration

### Age 5–7

- 1–3 teaching points per page.
- 2–4 steps per sequence.
- very short sentences;
- concrete nouns and actions;
- large illustrations;
- one interaction type.

### Age 7–10

- 2–5 teaching points per page.
- 3–6 steps per sequence.
- short explanatory sentences;
- simple cause/effect and classification;
- examples + guided practice.

### Age 10–12

- 3–6 teaching points per page.
- simple systems, tradeoffs, reflection, comparison;
- slightly denser text permitted;
- still prefer visual chunking over paragraphs.

## Language Rules

MUST use child-facing spoken Chinese unless user requests another register.

MUST prefer positive, specific action language:

`“把书放回原位” > “要有责任心”`

`“先停一下，再看看发生了什么” > “不要冲动”`

SHOULD use one idea per sentence.

NEVER use unnecessary adult jargon, abstract slogans, or dense definitions.
