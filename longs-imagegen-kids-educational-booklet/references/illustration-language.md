# Illustration Language

## Function

Every illustration MUST serve at least one role:

`explain | demonstrate | compare | sequence | locate | classify | motivate | confirm`

Delete illustrations with no instructional role.

## Object Rendering

MUST keep everyday objects immediately recognizable.

SHOULD use simplified but physically plausible forms.

MUST show correct object state when teaching action: toothbrush orientation, cup, clothes, schoolbag, chopsticks, food, clock, book, writing tool, etc.

NEVER prioritize cuteness over action accuracy.

## Action Rendering

For physical procedures:

- show hands/limbs clearly;
- avoid occluding the key contact point;
- keep tool position readable;
- use arrows/motion marks only when needed;
- keep before/after or step sequence consistent.

## Scene Rendering

Use minimal context required for recognition.

Preferred locations:

`desk | bedroom | bathroom | kitchen | dining table | classroom | schoolbag area | reading corner | playground`

Background detail SHOULD stay lower contrast than the teaching action.

## Visual Metaphors

Allowed when literal demonstration is insufficient:

`light bulb | magnifier | shield | path | bridge | puzzle | traffic sign | map | container | ladder`

MUST keep metaphors familiar to children.

NEVER use abstract futuristic AI imagery for ordinary child education.

## Icons

Use consistent icon family within a page and booklet.

Prefer simple watercolor/cartoon icons with clear silhouettes.

Do not mix photorealistic objects, flat icons, 3D toys, and watercolor illustrations on one page unless the selected style mode explicitly requires it.
