# Style Modes

MUST select one primary style mode per booklet unless user requests mixing.

MUST preserve the booklet's teaching hierarchy and text readability regardless of style.

Named styles are visual routing labels; content, identity, and layout constraints remain higher priority.

## Chinese Watercolor Picture Book Style / 中国水彩绘本风

Default Longs Kids mode.

`warm paper + watercolor wash + colored-pencil/ink contour + soft natural palette + hand-made textbook feel + gentle child characters + tactile everyday objects`

## Studio Ghibli Style / 吉卜力风

`soft hand-painted animation feel + warm natural light + lived-in environments + gentle expressions + organic detail + storybook atmosphere`

Keep booklet modules and text zones cleaner than cinematic scenes.

## 3D Animation Style / 3D 动画风

`soft 3D characters + rounded forms + readable facial expression + clean materials + soft studio lighting + child-friendly depth`

Avoid glossy advertising look.

## Lego Brick Style / 乐高积木风

`brick-built characters/objects + modular geometry + bright readable color blocks + toy-diorama spatial logic`

Keep educational objects recognizable within brick constraints.

## Disney Animation Style / 迪士尼动画风

`polished family-animation feel + expressive character acting + clean silhouettes + rich but controlled color + warm storybook lighting`

Avoid over-dramatic cinematic staging.

## Pixar Animation Style / 皮克斯动画风

`high-quality stylized 3D + appealing proportions + strong expression + soft global illumination + tactile materials + clear staging`

Keep page structure primary.

## Pop Mart Style / 泡泡玛特风

`designer-toy proportions + large head + compact body + collectible-toy finish + simplified facial expression + clean cute styling`

Avoid toy-commercial clutter.

## 3D Macaron Style / 3D 马卡龙风

`rounded 3D forms + pastel macaron palette + soft matte materials + gentle shadows + simple toy-like scenes`

Maintain sufficient contrast for text and instructional states.

## Chibi Cute Style / Q 版可爱风

`large head + small body + compact gestures + expressive face + simplified shapes + playful stickers/icons`

Avoid preschool infantilization when audience is older primary-school age.

## The Adventures of Tintin Style / 丁丁历险记风

`clear-line comic language + clean contour + flat readable color + simplified realistic environments + sequential action clarity`

Prefer for procedures, adventures, maps, and cause/effect sequences.

## American Cartoon Style / 美式卡通风

`bold contour + simplified expressive shapes + punchy color blocks + dynamic pose + clean comic readability`

Avoid chaotic action or excessive visual noise.

## Style Selection

Choose by teaching need:

- soft habits / life skills / reflection → `Chinese Watercolor Picture Book`;
- narrative / exploration → `Studio Ghibli` or `Tintin`;
- objects / mechanisms / playful STEM → `3D Animation`, `Lego Brick`, `3D Macaron`;
- strong character appeal → `Chibi`, `Pop Mart`, `Disney`, `Pixar`;
- energetic action / contrast → `American Cartoon`.

If user supplies a style reference image, reference image fidelity overrides the default descriptor while preserving booklet rules.
